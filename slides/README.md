# Workshop slides

This directory contains presentation slides shared for the W3C/GS1 Workshop
on E-commerce for Humans and AI Agents, 8-9 September 2026.

Speakers may submit slides by opening a pull request that adds their file to
this directory. Alternatively, speakers may email their slides to
`ran@w3.org`, and the organizers will upload them.

PDF is preferred for publication. A PPTX file or a link to a Google Slides
presentation may also be provided when necessary.

Please use a descriptive file name, for example:

`day-1-0930-ucp-amit-handa.pdf`

Presentations and slides will be made publicly available by default. Speakers
who have concerns about publication should contact the organizers before the
workshop.
